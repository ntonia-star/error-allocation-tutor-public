# 误差分配学习助手 · 公开源码版

这是从课程项目中独立整理的源代码快照，具有全新提交历史。**不附带任何教材、课件、课程知识摘录、原始页面图片、账号截图、实际密钥或原项目的历史提交。**

## 运行
Python 3.11+，正常运行无需第三方Python库：
```text
python -m backend.server
```
浏览器打开 http://127.0.0.1:8000 。初始知识库与练习为空；界面明确提示资料尚未导入，问答不调用模型编造答案。等影响分配和圆柱体程序计算工具可独立使用。

将`.env.example`复制为`.env`并自行配置DeepSeek密钥。环境变量优先于`.env`，密钥只由服务端读取。未导入知识时无需配置密钥也能查看界面和计算。

## 功能与架构
原生HTML/CSS/JS前端、本地KaTeX、安全Markdown；Python HTTP后端、中文BM25、真实来源引用、分层讲解、模型工具调用、受限AST算术、误差分配与验算。包含独立系统提示词、并发及请求限制、文件白名单和同源检查。

`backend/solutions.py`提供受控计算过程，只有相应引用ID确实存在才用于问答。该模板使用的ID为`rss`、`equal`、`derivation`、`adjustment`、`verification`、`cylinder`、`limit`及`conflict`；其意义由资料维护者核验，不能以空条目或虚构教材依据启用。
